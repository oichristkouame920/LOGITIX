APRES UNE ERREUR #3823 SUR V7.7.1
---------------------------------
- Installation neuve/base jetable : l'echec peut avoir laisse un schema partiel.
  Utilisez le SQL v7.7.2 complet et autorisez temporairement la reinstallation
  destructive uniquement si aucune donnee utile n'est a conserver.
- Base qui contenait des donnees utiles : ne relancez pas le SQL complet. Si la
  v7.7.1 avait ete lancee en mode destructif, restaurez d'abord votre sauvegarde,
  puis utilisez admin/bootstrap.php pour la migration non destructive v7.7.2.
